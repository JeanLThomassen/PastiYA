# PastiYA

PastiYA es una aplicación web para controlar el stock de medicamentos y saber cuándo hay que reponerlos. Calcula cuántos
días de cobertura quedan según la dosis diaria, avisa cuáles están sin stock o por acabarse, registra las compras y
envía una notificación push al teléfono. Está basada en una planilla de Excel de control y reposición de medicamentos.

## Tecnologías

- **TypeScript** en todo el proyecto (frontend, backend y código compartido)
- **React** y **Vite** para el frontend
- **Node.js** y **Express** para el backend
- **CSS** para los estilos
